3. RESEARCH GAPS FOUND IN THE BASE PAPER
----------------------------------------
Gap 1 - Post-event features (information leakage).
  The paper's WCFR Top-10 includes End_Time_dow and Distance(mi). Both are
  known only after the accident is cleared, so the model cannot be used to
  predict severity when an accident is first reported. Source (the data
  provider) is also in the Top-10; it reflects reporting differences between
  providers, not the accident itself.

Gap 2 - Class imbalance is not solved.
  Severity 4 is only 2.62% and Severity 1 only 0.87% of the data. In my
  reproduction, class balancing raised XGBoost Severity-4 recall from 4.6% to
  78.8%, but accuracy dropped from 84.2% to 55.6%. The paper itself names
  cost-sensitive learning as future work and does not give a reproducible
  weighting scheme.

Gap 3 - Severity is ordinal, but it is treated as plain multiclass.
  A Severity-4 accident predicted as 1 is a worse error than one predicted as
  3, but the paper's models and metrics treat all errors as equal.

Gap 4 - No time-based evaluation.
  The paper reports that accident patterns change from year to year
  (non-stationarity) but evaluates on an 80/20 split and cross-validation
  that mix all years, which can overestimate real-world performance on
  future accidents.

Gap 5 - Reproducibility.
  In my reproduction the paper's published Top-10 did not beat the
  all-features baseline, and no run matched the paper's Macro-F1 within 5
  points, because the sample, thresholds and WCFR implementation details are
  not fully specified.


4. PROPOSED NOVELTY
-------------------
Title (working):
  "Leakage-Aware, Cost-Sensitive WCFR Feature Selection for At-Onset
   Accident Severity Prediction with Temporal Validation"

The idea, in steps:
  a) At-onset feature set: keep only features available when the accident is
     first reported (start time, location, weather, road features); remove
     End_Time, End_Lat/End_Lng, Distance and Duration. Measure how much of the
     paper's performance came from post-event features.
  b) Run WCFR (and mRMR, CMIM, ReliefF for comparison) on this at-onset set,
     with a zero-aware discretization fix for zero-inflated features such as
     Precipitation (found in my reproduction).
  c) Cost-sensitive and ordinal learning: use a severity cost matrix and
     per-class decision thresholds tuned on validation data, to find a better
     trade-off between Severity-4 recall and overall accuracy than simple
     "balanced" weights.
  d) Temporal validation: train on 2016-2021, test on 2022-2023, and report
     how stable the selected features are over time (Jaccard similarity).
  e) Explainability: SHAP analysis of the at-onset model to show which
     factors drive severe (3-4) accidents.

6. EVALUATION
-------------
- Macro-F1 (main metric), accuracy, balanced accuracy
- Per-class recall and precision, especially Severity 3 and 4
- Ordinal error: mean absolute error between true and predicted severity
- Random split vs temporal split (2022-2023 test)
- Feature stability: Jaccard similarity of Top-10 features across folds
  and across years
- Statistical significance: repeated runs with different seeds
