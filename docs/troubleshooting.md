# Troubleshooting log

| Stage | Command | Error | Fix |
|---|---|---|---|
| 4 | `python notebooks\train_small_lgbm.py` (first draft) | `numpy._core._exceptions._ArrayMemoryError` while one-hot encoding 300,000 rows (7.9 GB RAM, ~0.5 GB free) | Kept `OneHotEncoder(handle_unknown="ignore")` with its default sparse output; LightGBM trains directly on the sparse matrix. Also set `n_jobs=2` and read only the needed columns with `usecols=`. Training then completed; bundle is 3.15 MB. |
| 7 | `Get-Process -Id <pid>` after `Stop-Process` | PowerShell exits with code 1 ("Cannot find a process") | Expected: the Flask process was already stopped. Port 5000 was confirmed free with `Get-NetTCPConnection -LocalPort 5000`. |
| 8 | `ng.cmd version` | `Program 'ng.cmd' failed to run: The system cannot find the file specified` (`cmd.exe` is not reachable from this PowerShell session; `ng version` also reported `Package Manager : npm <error>`) | Used the PowerShell shim `ng` (ng.ps1) and `node node_modules\@angular\cli\bin\ng.js` instead of `.cmd` shims. Ran `ng new` with `--skip-install` and then `npm install` myself; for `npm run build` / `npm test` set `$env:npm_config_script_shell='C:\Program Files\Git\bin\bash.exe'` so npm scripts run through Git Bash. |
| 8 | `ng serve` (Angular 22.2) | Dev server exits right after `Application bundle generation complete` (exit code 9/127, nothing listens on port 4200, no error message) | The native file watcher crashes on this machine. `ng serve --watch=false` and `ng serve --poll 2000` both stay up; used `ng serve --proxy-config proxy.conf.json --poll 2000` for local runs. `ng build` is not affected. |
| 8 | PowerShell polling loop with `curl.exe` (no `-m`) while the dev server was down | Loop hung until the tool timeout | Added `-m 5` to every `curl.exe` call in wait loops. |
| 10 | `python backend\app.py` started right after `ng serve` | `OpenBLAS error: Memory allocation still failed after 10 retries, giving up.` and Flask exited (free virtual memory was ~200 MB) | Started Flask first with `$env:OPENBLAS_NUM_THREADS='1'; $env:OMP_NUM_THREADS='1'; $env:MKL_NUM_THREADS='1'`, waited for `/health` = 200, then started `ng serve`. |
| 10 | POST `/api/predict` through the dev proxy with Flask stopped | `HTTP/1.1 502 Bad Gateway` (dev server log: `http proxy error: /predict ... ECONNREFUSED 127.0.0.1:5000`) | Expected behaviour. The UI shows `HTTP 502 Bad Gateway: the prediction API is unavailable. Start the Flask server and try again.` |
